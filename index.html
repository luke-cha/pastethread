One ⌘V. The right paste for every app.

Your terminal and AI coding agents get the file path. Notes, chat, and design apps get the real image or file. Every copy is kept in a history sorted by text, images, and files.

A menu bar app for macOS 14 or later · Coming soon to the Mac App Store

Why

Some terminals can't paste an image at all, and AI agents only need its path. Coding tools often attach the image when a path is all you want. Pastethread gives each app the right thing — without changing how you work.

Paste Rules

original — paste the image or file itself (notes, chat, design apps).

original + path — keep the original and paste the file path as text (terminals).

path only — paste just the path (coding tools that would attach the file).

Choose per app and per file type (images, videos, other files, or your own extensions) from the menu bar, the History window, or Settings. Paths can be plain, shell-escaped, or quoted, and terminals start with a ready-made preset.

Copy history, sorted by type

Find text, images, and files with one click, preview image files and a video's first frame, and open it anywhere with ⌥⌘F. Type, pick, press Return — the paste rule for the app you came from is applied. Text inside screenshots is searchable, and pins, boards, and saved views keep what matters close.

Private by design

Everything stays on your Mac. No account, cloud, analytics, or tracking. Pastethread never presses ⌘V for you and needs no Accessibility permission. Privacy Policy.
